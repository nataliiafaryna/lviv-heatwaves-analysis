# lviv-heatwaves-analysis
Аналіз динаміки хвиль тепла та біокліматичного стресу у Львові (1990-2025).
## Про проєкт
Дослідження довгострокової кліматичної динаміки у Львові з фокусом на хвилі тепла, посушливі періоди та кумулятивний біокліматичний стрес. Мета - перевірити гіпотезу щодо збільшення частоти екстремальних температурних подій та оцінити реальне фізіологічне навантаження на людину.

## Інструменти 
- **Мова:** Python
- **Бібліотеки:** pandas, numpy, scipy, pymannkendall, matplotlib
- **Дані:** Meteostat API (WMO ID: 33393)

## Методологія
1. **Метеорологічний підхід (Compound Events):** Розраховано сумісне виникнення хвиль тепла ($T_{max} > T_{p90}$) та посух. Застосовано плаваючу рангову кореляцію Спірмена (10-річні вікна).
2. **Біокліматичний підхід (EHF):** Реалізовано методологію *Nairn & Fawcett (2015)*, що враховує нічні температури та акліматизацію населення.

## Ключові результати
- **Зростання стресу:** Біокліматичне навантаження ($EHF_{load}$) має значущий тренд зростання (+33.8 °C² за десятиліття, $p = 0.002$).
- **Ефект посилення:** Зв'язок між хвилями тепла та посушливими періодами стає міцнішим з роками — вони частіше підсилюють одна одну.
- **Аномалія 2024:** Літо 2024 року стало історичним рекордсменом за тривалістю (39 днів теплового стресу) та сумарним навантаженням.
